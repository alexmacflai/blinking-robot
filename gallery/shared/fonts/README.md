# Shared controls fonts

Bundled Fira Sans and Fira Mono files used by the local controls sidebar, so
authoring previews do not depend on a machine-level font installation or a
remote font service.

## Context

`[gallery]` `[controls]` `[shared]`

## Files

- `fira-sans-regular.ttf` and `fira-sans-medium.ttf` — UI text and actions.
- `fira-mono-regular.ttf`, `fira-mono-medium.ttf`, and `fira-mono-bold.ttf` —
  titles, values, chips, and diagnostics.
